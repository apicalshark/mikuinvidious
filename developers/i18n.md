# Internationalization

UI ships English, Simplified/Traditional Chinese, Japanese. **Interface chrome
only — never video titles, comments, danmaku** (Bilibili's content).

Resolution order: `?lang=` ＞ `lang` cookie ＞ `Accept-Language` ＞
`default_locale` (`DEFAULT_LOCALE`). `SUPPORTED_LOCALES` allowlist hides locales;
unset = all enabled.

Strings live in `python/`, `templates/`, `static/themes/modern/js`, collected via
`i18n_strings.py`. After changing them:

```bash
npm run build:i18n   # pybabel extract → pomerge → po2json
npm run check:i18n   # CI check — PRs must pass it
```

New locale: copy `locales/messages.pot` to
`locales/<tag>/LC_MESSAGES/messages.po` (e.g. `pt_BR`), fill `Language` /
`Plural-Forms`, translate, build, PR. Untranslated strings fall back to English.
No code changes needed.

## These docs

One directory per locale (`/` English, `/zh-TW/` Traditional Chinese). New
language: add `/<code>/` with translated pages, register label/nav/sidebar in
`.vitepress/config.mts`. Fix slugs first so translated URLs stay stable.
