# 多國語系

介面目前有英文、簡體中文、正體中文、日文。**只翻介面，不翻影片標題、留言和彈幕**（那些是 Bilibili 的內容）。

## 語言決定順序

`?lang=` 參數 ＞ `lang` cookie ＞ `Accept-Language` ＞ `default_locale`（`DEFAULT_LOCALE`）。管理員可以用 `SUPPORTED_LOCALES` 白名單藏掉某些語系，不設就全開。

## 加字串／加語系

字串散在 `python/`、`templates/`、`static/themes/modern/js`，由 `i18n_strings.py` 收攏。改完跑：

```bash
npm run build:i18n   # pybabel 抽字串 → pomerge → po2json
npm run check:i18n   # CI 檢查用，沒過不要送 PR
```

新語系：把 `locales/messages.pot` 複製成 `locales/<tag>/LC_MESSAGES/messages.po`（例如 `pt_BR`），填好 `Language`／`Plural-Forms`，翻完建置、送 PR。沒翻到的字串自動掉回英文，不用改程式。

## 這份文件的多語規劃

GitBook 用 variants 做多語：一個語系一個 space。`doc/gitbook-zh-TW/` 是正體中文主版，以後英文版另外開 `doc/gitbook-en/` space 掛成 variant，前台就有語言切換器。頁面 slug 先固定，翻譯版網址才不會亂跳。
