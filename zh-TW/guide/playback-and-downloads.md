# 播放器與下載

MikuInvidious 配備先進的媒體播放與背景下載引擎，專為強韌穩定性、零客戶端追蹤與極致流暢度而設計。

---

## 1. 影片播放器與畫質選擇

影片播放器採用 `dash.js`（v5 representations API）並搭配現代化、適配行動裝置的控制介面。

### 畫質階層
- **免登入階層（預設）**：支援高達 **1080P 高畫質**（1080P、720P、480P、360P），完全無需登入或個人帳號。
- **高畫質與會員階層**：若站長在伺服器端設定了有效的 Bilibili 憑證，系統將自動解鎖 **1080P 60fps**、**4K 超高畫質** 與大會員付費番劇內容。

### 鍵盤快捷鍵

當播放器獲得焦點時，可使用以下標準快捷鍵：

| 按鍵 | 操作動作 |
| :--- | :--- |
| <kbd>空白鍵</kbd> 或 <kbd>K</kbd> | 播放 ／ 暫停 |
| <kbd>→</kbd> ／ <kbd>←</kbd> | 快轉 ／ 倒轉 5 秒 |
| <kbd>L</kbd> ／ <kbd>J</kbd> | 快轉 ／ 倒轉 10 秒 |
| <kbd>↑</kbd> ／ <kbd>↓</kbd> | 調高 ／ 調低音量（5%） |
| <kbd>M</kbd> | 靜音切換 |
| <kbd>F</kbd> | 全螢幕切換 |
| <kbd>D</kbd> | 彈幕顯示開關切換 |

## 2. 彈幕控制與微調

彈幕由後端即時拉取轉碼為 XML，並在播放器畫布上進行高效能平滑繪製。

- **開關**：點選控制列上的彈幕圖示，或按下鍵盤快速鍵 <kbd>D</kbd>。
- **偏好自訂**：於播放器內的設定齒輪選單中可即時微調：
  - **不透明度**：調整彈幕透光程度，避免文字遮擋重要字幕或畫面。
  - **字體縮放**：依據螢幕尺寸自訂文字大小。
  - **飛行速度**：微調彈幕飄過螢幕的時間節奏。

---

## 3. 串流穩定性與鏡像節點自動容錯

MikuInvidious 的媒體代理完全接管了所有與上游 Bilibili CDN 的通訊：
- **鏡像自動容錯（Failover）**：若上游某個 CDN 節點發生壅塞、降速或連線中斷，伺服器將在數秒內自動切換至備援的健康鏡像，確保播放不中斷。
- **Socket 連線複用**：伺服器跨視訊分段複用 TCP+TLS 連線池（`_PlaybackKeepAlivePool`），免除頻繁交握造成的延遲阻滯，顯著消除緩衝等待。
- **隱私隔絕**：您的瀏覽器絕不直接連線至任何 Bilibili CDN 位址（`*.bilivideo.com`）。

## 4. 背景下載管理功能

當站長開啟下載權限時，任何影片均可直接從播放頁下載至本機。

```
+-----------------------------------------------------------+
| [點選下載 1080P]                                          |
|                                                           |
| 1. 加入佇列   --> 2. 分段下載     --> 3. ffmpeg 封裝      |
| (多軌併發)        (自適應避障)        (可隨選播放的 MP4)  |
+-----------------------------------------------------------+
```

### 如何下載
1. 在影片播放頁點選播放器下方的 **下載** 按鈕。
2. 選擇您期望的解析度。
3. 頁面底部將滑出專屬的浮動下載進度面板。

### 下載階段說明
進度面板將即時展示目前的處理狀態：
1. **Queued（排隊中）**：下載任務已登記至伺服器背景佇列中。
2. **Resolving（解析簽名）**：伺服器向上游取得最新的高畫質音訊與視訊串流時效金鑰。
3. **Downloading（分段下載）**：系統以 32 MB 為區塊同時拉取視訊與音訊分段，並搭載自動降速看門狗，避免遭 CDN 封鎖懲罰。
4. **Muxing（格式封裝）**：伺服器呼叫 `ffmpeg -c copy -movflags +faststart`，將分離的影音軌無損合成為標準的 `.mp4` 檔案。
5. **Ready（已就緒）**：封裝完成，系統自動觸發瀏覽器的檔案儲存對話框。

> [!TIP]
> 下載任務在伺服器背景進行，期間您可以自由切換頁面、觀看其他影片或進行搜尋，下載不會中斷。若欲終止任務，點選 **取消** 即可立即釋放伺服器上游連線並清理暫存檔。

## 5. 直播串流播放

直播間支援低延遲原生音訊與視訊串流：
- **串流格式策略**：預設採用極致低延遲的 FLV 協定（基於 `mpegts.js`），並支援 HLS 主播放清單（基於 `hls.js`）作為備援。
- **即時彈幕通訊**：伺服器端長連線至 Bilibili 直播聊天室伺服器，並以低資源消耗方式即時廣播彈幕至您的瀏覽器。
