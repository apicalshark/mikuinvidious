# 使用者指南總覽

歡迎使用 MikuInvidious —— 一款免費、輕量且注重隱私的 Bilibili 網頁前端（靈感源自 Invidious）。

MikuInvidious 讓您可以在不使用官方應用程式、不受侵入式追蹤器或分析腳本干擾、且無需登入帳號的情況下，順暢瀏覽、觀看、閱讀與聆聽 Bilibili 影音內容。

---

## 為什麼選擇 MikuInvidious？

- **零追蹤且免登入**：瀏覽影片、番劇、專欄文章與創作者空間均無需登入帳號。您的觀看紀錄、IP 位址與瀏覽器數位指紋絕不會傳送給 Bilibili 官方。
- **隱私優先的代理架構**：所有媒體串流（影片、音訊、直播）與圖片均由 MikuInvidious 伺服器代理抓取並轉發給您的瀏覽器。Bilibili 僅能看到實例伺服器（或其跳板 Proxy），無法得知您的真實身分。
- **萬用搜尋列**：支援直接在搜尋列貼入任何 Bilibili 官方網址（包含 `b23.tv` 短網址與各類分享連結），系統會自動解析並徹底清除所有追蹤參數。
- **純聽模式（`?listen=1`）**：為所有影片提供純音訊播放介面，在行動裝置或背景分頁播放時可大幅節省流量與 CPU 資源。
- **強韌的播放體驗**：支援高畫質 DASH 串流與自動 CDN 節點容錯切換、流暢彈幕顯示，以及背景多軌自動封裝 MP4 下載功能。
- **簡潔介面與佈景主題**：基於 Tailwind CSS 構建的現代化響應式介面，支援系統隨動、淺色與深色模式，並具備完整多國語系支援。

---

## 介面功能導覽

1. **頂部導覽列**：
   - **搜尋列**：支援關鍵字搜尋、直接代號跳轉與官方網址解析。
   - **番劇索引**：按季度、類型瀏覽各類官方正版動畫、電影與紀錄片。
   - **佈景主題切換**：一鍵在淺色、深色與系統預設之間切換。
   - **語言選單**：自由切換 English、正體中文、简体中文與日本語。
   - **觀看歷史**：本機觀看歷史紀錄（資料僅儲存於您瀏覽器的 `localStorage`，絕不上傳伺服器）。
   - **偏好設定**：設定預設播放畫質、彈幕外觀與播放器行為。

2. **核心頁面**：
   - **首頁與分區動態**：熱門推薦與各分區最新影音探索。
   - **影片播放頁**：高畫質串流播放、多 P 分集切換、標籤、關聯推薦與留言評論區。
   - **番劇專題頁**：作品簡介、集數網格、PV 預告片與 Nyaa 種子整合。
   - **個人空間**：創作者主頁、影片投稿列表、動態專欄與標準 JSON 訂閱摘要。
   - **直播間**：即時直播播放器、彈幕聊天室與格式切換（FLV / HLS）。
