# Internationalization

The UI currently ships English, Simplified Chinese, Traditional Chinese, and
Japanese. **Only the interface chrome is translated — never video titles,
comments, or danmaku** (that's Bilibili's content).

## Language resolution order

`?lang=` param ＞ `lang` cookie ＞ `Accept-Language` ＞ `default_locale`
(`DEFAULT_LOCALE`). Operators can hide locales with the `SUPPORTED_LOCALES`
allowlist; unset means all enabled.

## Adding strings / adding a locale

Strings are scattered across `python/`, `templates/`, and
`static/themes/modern/js`, collected via `i18n_strings.py`. After changing them:

```bash
npm run build:i18n   # pybabel extract → pomerge → po2json
npm run check:i18n   # CI check — don't open a PR without passing it
```

New locale: copy `locales/messages.pot` to
`locales/<tag>/LC_MESSAGES/messages.po` (e.g. `pt_BR`), fill in `Language` /
`Plural-Forms`, translate, build, open a PR. Untranslated strings fall back to
English automatically; no code changes needed.

## Multi-language plan for these docs

This site uses one directory per locale (`/` for Traditional Chinese, `/en/` for
English). To add a language: create `/<code>/` with translated pages, then register
its label, nav, and sidebar in `.vitepress/config.mts`. Fix page slugs first so
translated URLs stay stable.
